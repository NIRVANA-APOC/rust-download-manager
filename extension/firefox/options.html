关于原生宿主

扩展依赖原生消息宿主 com.rdm.download。首次使用请先构建 RDM 并运行 scripts/install-firefox-host.ps1，然后在 about:debugging → 此 Firefox → 临时载入附加组件 中加载本扩展。 安装完成建议重启 Firefox，让原生宿主注册表项生效。

权限说明：downloads（取消/清理被接管的下载）、webRequest （只读观察请求/响应头，MV3 下无法阻塞请求）、cookies（透传登录态）、 nativeMessaging（与本机 RDM 通信）、storage（保存设置与最近记录）、 contextMenus / alarms（右键菜单与状态轮询）。

已知限制：极小的文件可能在 downloads.onCreated 之前就已完成，此时扩展会删除 浏览器下载文件并改由 RDM 重新下载；被接管的下载在 RDM 中不会显示 Firefox 的来源标签。
