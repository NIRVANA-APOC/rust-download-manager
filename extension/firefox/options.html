    隐私与权限

    允许 RDM 使用本页登录态？

    Cookie 只会在浏览器 → 本机 RDM 进程内存中传递，不上传、不写日志/磁盘。 仅对需要登录的下载生效，可随时在设置中关闭。

    权限说明
    • downloads：取消并清理被接管的浏览器原生下载。
    • webRequest：只读观察请求/响应头（Referer、Cookie、Content-Length），MV3 下不能阻塞请求。
    • cookies：仅在你开启时透传登录态，只在本机进程间传递。
    • nativeMessaging：与本机 RDM 原生宿主通信，不联网。
    • scripting：仅在用户主动动作时读取当前标签页链接/选中文本或注入一条交接提示。
    • storage / contextMenus / alarms：保存设置与最近活动、右键菜单、状态轮询。

    不收集浏览记录、不上传任何数据；页面注入默认关闭，Cookie 默认不转发。

          RDM 浏览器接管
          —
          —
        
    
        
    
          RDM 是纯 Rust 多线程下载器；扩展只负责把下载交给桌面端，连接数、动态线程规划、分类与
          SHA-256 校验由桌面端统一管理。
        
    
        
    
          开源许可与使用文档见仓库 README 与 docs/extension-protocol.md；扩展不包含远程依赖或外部 CDN。
